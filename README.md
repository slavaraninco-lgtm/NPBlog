# NPBlog
> Редактор блогов для статичных хостингов без PHP(отсюда и название - No PHP Blog)

# Что он умеет?
- Удобное визуальное редактирование с большим функционалом
- Редактор HTML-кодом
- Отправка блогов по (S)FTP на хостинг прямо из редактора
- Мульти-блог
- Редактор картинок
- Вставка медиафайлов
- Times New Roman 14!!!
- И другое. А вот поставьте и сами увидите

# Установка
1. **Установите веб-сервер и расширения**
*[17.10.2026 23:27] ftod: напиши шо это как его, апач желательнее да*  
*На разных системах установка веб-сервера отличается. Новичкам на винде будет удобнее XAMPP. Как устанавливать на свой дистрибутив линукса - ищите в тернете*  
*Для корректной работы также требуются расширения: `php-ssh2 php-mbstring php-zip php-xml php-dom` и библиотека `libssh2`(для линукс дистрибутивов).*  
*Расширения ставятся через пакетный менеджер(на линуксе) или включаются в конфиге (XAMPP).*

2. **[Скачайте](https://github.com/slavaraninco-lgtm/NPBlog/releases/latest/) сам редактор**
3. **Распакуйте все файлы в корневую директорию вашего веб-сервера**
*На XAMPP это `%ПАПКА УСТАНОВКИ XAMPP%/htdocs/`, на nginx/apache обычно `/var/www/html/`*
4. (Для UNIX) **Настройте права**
*В папке с редактором:*  
```bash
sudo chown -R www-data:www-data .
sudo chmod -R 775 data autosave data_backup editor_backup includes
```
5. (Для nginx) **Отредактируйте конфиг**
*Инструкции [тут](https://github.com/slavaraninco-lgtm/NPBlog/blob/main/nginx.conf.example)*
6. **Запустите веб-сервер, зайдите на айпишник, пройдите первоначальную настройку и РАДУЙТЕСЬ УРА ДА НАЛИВАЙ УРА ДА**

# А почему No PHP Blog, если весь редактор написан на PHP?
Сам редактор - да. Но сами статьи - статичные файлы(html + css + js), которые уже можно загрузить на любой хостинг. PHP нужен **только** для редактора.
